Schedule Sync privacy policy

Effective September 29, 2026. Schedule Sync is a personal automation operated by the owner of the GitHub account bbishay.

Data used and purpose

The app downloads a published schedule PDF, identifies entries associated with the configured person, and copies event times, instructors, locations, notes, and source links into a dedicated Google Calendar. It reads and modifies entries in calendars created by the application to prevent duplicates and apply schedule changes.

Google access

The owner grants the Google Calendar permission calendar.app.created. The app uses an OAuth refresh token to maintain authorized access. It does not request access to Gmail, contacts, Google Drive, or unrelated calendars. Google user data is used only to provide the requested calendar synchronization, not advertising, sale, or model training.

Storage and service providers

Google stores calendar entries. For cloud execution, GitHub Actions runs the application, and GitHub repository secrets store the OAuth credential in encrypted form. The credential is made available to the authorized workflow at runtime. The source repository is private. Small download-confirmation records may be held in the Actions cache; run status and errors appear in private workflow logs. PDFs are downloaded temporarily on hosted runners and are not intentionally uploaded as artifacts or cached. Local Windows installations may retain PDFs, previews, and logs until the owner removes them; their saved authorization token is encrypted with Windows DPAPI.

Retention and control

Calendar entries remain until removed by synchronization or the owner. GitHub logs and cache follow GitHub retention and eviction settings. The owner may disable the workflow, remove repository secrets and retained logs/cache, delete local data, and delete the dedicated calendar. Google access can be revoked through the owner's Google Account third-party connections settings. Revoking access stops future access but does not automatically remove existing calendar entries.

Sharing and contact

Data is processed by Google and GitHub as described above and is not deliberately disclosed to other recipients. The owner controls repository and calendar sharing. Contact the maintainer through the app information repository; do not post credentials or private schedule details in public issues.
